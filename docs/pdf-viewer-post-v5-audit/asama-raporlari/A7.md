## Kapsam ve değişiklikler

- Özel stream/access, public download, share-list ve parola doğrulama API yanıtlarında `private, no-store`, `no-referrer` ve uygun yerlerde `nosniff` başlıkları tutarlı hale getirildi. İndirme sınırının dolması `403` olarak yanıtlanıyor.
- PDF görüntüleyicide sona eren erişim lease'i ve ağ hatası için açık yeniden deneme yolu ve kullanıcıya anlaşılır süre sonu mesajı eklendi.
- Yeni boş tarayıcı context'inde kimliği doğrulanmamış özel stream, access ve share-list istekleri denendi. Sentetik testte ilk PDF byte'ı, özel dosya ID'si veya kayıt metadatası verilmedi; yanıtlar `401` ve özel API cache politikası taşıdı.
- Public share senaryolarında yanlış parola/token/item/share, sona ermiş ve iptal edilmiş bağlantı, indirme sınırı, aralık isteği, parola cookie'si ve yönetici liste kapsamı test edildi. Sentetik hostile dosya adında başlık enjeksiyonu oluşmadı; token içeren değerler kanıta yazılmadı.
- 401/403/404/416/429/500/503 hata enjeksiyonu sınırlı istek sayısıyla UI hata durumuna ulaştı. 503 sonrası çevrimiçi olma olayıyla kurtarma ve ağ hatasında manuel tekrar denendi; sonsuz yükleme durumu görülmedi.
- Sentetik PDF ile print Blob URL, iframe temizliği, `afterprint`, 60 saniye ve 20 dakika temizlik zamanlayıcıları doğrulandı. Gerçek OS yazdırma önizlemesi otomatik test edilmedi.
- Sentetik PDF JavaScript action'ı, güvenli dış bağlantı, XSS-benzeri başlık/metin ve hızlı A→B dosya geçişi test edildi. B belgesinde A'nın bağlantısı/metni/print Blob boyutu kalmadı.
- Daha belirli `next.config.ts` kuralları API referrer politikasını ve `/p/:token` no-index/referrer davranışını kapsıyor. Geliştirme sunucusundaki public sayfa yanıtı `Cache-Control: no-cache, must-revalidate` verdi (`public` değildi); üretim sayfası davranışı bu yerel gözlemle kanıtlanmış sayılmıyor.
